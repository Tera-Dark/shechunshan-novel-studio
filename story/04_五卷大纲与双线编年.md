# 八卷千章级连载架构与分卷详纲（江湖仙侠终定版 · 约 960–1050 章）

> **千章防注水铁律**：
> 1. 每一卷严格拆分为 **3–4 个递进式单元诡案（约 90–105 章）+ 1 场收网高潮战（约 25–30 章）**，杜绝一卷只有两个案子导致中段注水。
> 2. 每一卷均绑定 **“同心链锁脉境”、“替劫死契消解计数（365 -> 0）”与“枯木回春五候（死灰 -> 抽芽 -> 凝脉 -> 通窍 -> 圆满）”** 三条主脉，并确保每个单元诡案都带着风物行规与人性悲歌。

---

## 第一卷 · 南荒赊命铺（第 1–120 章）
- **双脉消长**：同心链【初重 · 牵丝分痛三成】 / 替劫死契：`365 -> 335 道` / 灵脉：【死灰候】
- **四案递进结构（彻底撑实 120 章）**：
  1. **案一：城南赵府画皮阴契案（第 3–35 章）**——表为丑女买皮吞影，实为生父赵元德拿女儿八字抵债；陆砚寒暗中派人销毁线索并借司命台“勘验玉符”卡住谢峥权限，楚越靠无灵脉算阵破局并顺势拉近贴耳密谋。
  2. **案二：盲画师与活人试药桩案（第 36–65 章）**——顺着“错字铜钱”追查，发现城外废窑里竟暗藏模仿“万劫潭”古法做活人试药的残党，王屠户与李大娘在暗中出手擦屁股时彻底向楚越坐实“甲等戍边营暗卫”底细。
  3. **案三：荒村冥婚借寿案（第 66–95 章）**——穷书生与病弱新娘的冥婚悲歌，牵出底层百姓被骗签契的惨状；楚越于暴雨夜冷笑借天雷反噬劈碎祠堂，“尘埃里的神明锋芒”初次震撼谢峥与暗卫。
  4. **收网战：鬼窟百鬼讨债与雪夜系裘（第 96–120 章）**——幕后黑手掳走阿财逼问天机算，谢峥在楚越画押定罪的刹那太渊剑出鞘屠尽鬼窟，回身却蹲在泥水里替发抖的楚越仔细系紧狐裘领口；屋檐上陆砚寒冷笑邀约“江南见”。

## 第二卷 · 江南千灯黑市（第 121–260 章）
- **双脉消长**：同心链【二重 · 寒髓渡阳】 / 替劫死契：`335 -> 285 道` / 灵脉：【死灰微动】
- **三案递进结构**：
  1. **案一：十里画舫沉船赌命局（第 121–170 章）**——江南士子拿三十年气运押注登科，温疏泠（百晓茶楼）借茶局试探二人关系。
  2. **案二：水下无底鬼市“换命灯”案（第 171–215 章）**——失明歌姬替死去青梅点长明灯还债的人性悲剧；二重寒毒首次全面爆发，受被迫在攻滚烫怀里咬唇汲取纯阳灵力。
  3. **案三：无名补心丹失窃与暗巷抢人战（第 216–260 章）**——百晓楼同时丢失两份互瞒对方的药单；陆砚寒设鸿门宴用折扇挑楚越下颌，彻底引爆谢峥恶犬凶性按墙护食；沉船密匣摸出北境“长生丹方铜牌”。

## 第三卷 · 北境凌霄剑阁（第 261–400 章）
- **双脉消长**：同心链【二重峰值】 / 替劫死契：`285 -> 230 道` / 灵脉：【枯木抽芽（破题名场面）】
- **三案递进结构**：
  1. **案一：雪原驿站冻尸无魂案（第 261–300 章）**——初入北境遇寒门剑修逃亡惨死，结识光风霁月的大师兄沈孤遥。
  2. **案二：天池长生泉抽寿案（第 301–350 章）**——揭穿所谓灵泉竟融着数千外门弟子生机；长期纯阳渡气之下，楚越干枯五年的灵脉首次抽出第一丝新芽。
  3. **案三：雪原剑冢万寿血阵与“交剑缝符”（第 351–400 章）**——雪夜谢峥双手奉上刻满三千六百条天规的太渊剑柄；暗镖偷袭撕开外袍，谢峥摸到受在卷一至卷三途中亲手暗缝进去的**九张心血护心符**当场红了眼眶，首次确信双向死守！沈孤遥燃尽剑意破开大阵，剑阁老祖临死指向东海。

## 第四卷 · 东海沉渊蛟宫（第 401–540 章）
- **双脉消长**：同心链【三重 · 灵犀共鸣】 / 替劫死契：`230 -> 175 道` / 灵脉：【凝脉初成】
- **三案递进结构**：
  1. **案一：珍珠渔村“蛟泪换魂”案（第 401–450 章）**——老母亲卖掉记忆换儿子出海平安却忘了自己是谁的悲剧；同心链正式晋入三重灵犀共鸣。
  2. **案二：珊瑚黑市原始玉简争夺战（第 451–495 章）**——三重共鸣之下，楚越一次次清晰感应到谢峥藏在白袍下克制欲望时发烫勒红的腕骨。
  3. **案三：无归海眼塌方与水牢强吻（第 496–540 章）**——蛟主敖沧寂企图强留楚越做专属算师，塌方瞬间受切断感应独自坠渊救人；大司命疯魔屠妖捞回受后，在水牢里发狠咬破他唇角：“再敢独自去死，就把整个东海陪葬！”

## 第五卷 · 中州玉京权谋局（第 541–680 章）
- **双脉消长**：同心链【三重明牌撩拨期】 / 替劫死契：`175 -> 120 道` / 灵脉：【通窍小成】
- **三案递进结构**：
  1. **案一：寒门状元文脉盗窃案（第 541–590 章）**——受坐着轮椅装病用紫毫当众劈开文庙盗运大阵。
  2. **案二：皇室长生傀儡案（第 591–635 章）**——老皇帝拿皇子阳寿续命的荒诞权谋，两人已学会借三重链纹心跳暗通款曲。
  3. **案三：陆氏藏私秘阁反杀与改判书残卷（第 636–680 章）**——陆砚寒联手朝堂设“强夺契绝杀局”，楚谢里应外合当众拆穿陆氏秘阁丑闻，剥去陆砚寒官服押入大牢；受趁机在司命密库翻出五年前《死刑改判书》残卷，朱批直指五百年旧案。

## 第六卷 · 幽冥无间与归墟镜渊（第 681–800 章）
- **双脉消长**：同心链【四重 · 命骨同生护心印】 / 替劫死契：`120 -> 70 道` / 灵脉：【通窍巅峰】
- **三案递进结构**：
  1. **案一：忘川摆渡买路钱黑幕（第 681–720 章）**——亡魂攒一辈子功德仍被司命旧派截留名额，引出《人间赊命契》最终源头。
  2. **案二：生死簿残页十殿审讯（第 721–755 章）**——受开始顺着《死刑改判书》反推五百年前隐秘关联。
  3. **案三：归墟镜渊塌陷与全盘掀牌（第 756–800 章）**——万劫潭半块硬麦饼、太渊九死劫死契、五年蓄谋真相在同一夜全部映出；麦饼锦囊掉落后谢峥慌乱捡两次没抓稳，受红着眼拽住衣领主动吻上去挑明一切：“换我走过来牵你。”

## 第七卷 · 九重天司命本台（第 801–920 章）
- **双脉消长**：同心链【四重双生共振】 / 替劫死契：`70 -> 0 道（死契尽销）` / 灵脉：【重塑圆满】
- **三段推进**：
  1. **前段（801–845 章）**：玉清天尊调三千仙官围剿问罪台，抛出血淋淋的“牺牲底层供养天梯”终极理念辩论。
  2. **中段（846–890 章）**：受悬空执“不赊”紫毫布九重天机阵，当三界水镜直播摊开千年典命贪墨铁证；攻折断大司命玉冠，一剑劈碎千年玄铁算盘！
  3. **终局破天（891–920 章）**：三百六十五道替劫死契当众消解殆尽，楚越枯竭灵脉轰然重塑圆满，两人并肩重立《三界契约律》。

## 第八卷 · 春山返乡录（第 921–1000 章）
- **全篇收尾**：新律颁行，天下再无典命邪契。双双辞去神籍重返南荒翻修《春山茶肆》。阿财化形历劫、王猛（王屠户）改行正经卖肉、谢疏淮哭着端茶送水。强迫金链封印早已解除，楚越却在茶肆开张日笑着把金链重新扣回两人腕上——从当年被迫锁进三丈，到余生心甘情愿共守一整座春山。
