# 角色档案全集：双主角深层心理、时间线逻辑补丁与近景配角卡

## 一、 攻：晏寒江（官号“太渊司命”）

- **核心定位**：**披着白玉朝服的万劫潭恶犬 · 漫长等待后的极度偏爱者**
- **战斗与温养**：主修太渊天律剑意，下凡受《降凡印》压制；私下为许知微极寒髓海专门改修了纯阳温养心法。

### 1. 【核心逻辑补丁】为何当年同朝为官，许知微没认出他就是万劫潭小疯子？
- **五重物理与天律隔绝（彻底堵死马甲漏洞）**：
  1. 五百年前万劫潭试药坑底，他无名无姓、满脸溃烂疤痕且声带被毒药烧哑，只用一双死水般的野狼眼盯着人看；
  2. 后来他侥幸爬出死人堆、渡劫飞升**重塑仙骨**，容貌身量脱胎换骨，并改姓为“晏”；
  3. 初入司命台时他常年戴着遮住下半张脸的**玄铁半面司命面具**（只为防天机算一眼看透自己），且司命主官受**天律神印遮蔽命格**——连天机榜魁首都算不到他的真实过去。
  4. 因此四百八十年前同朝时，许知微只觉得这个新晋冷面大司命性格阴郁古怪、总爱冷冰冰挑自己毛病，纯粹出于“看这么个好苗子快死在九死劫里太可惜”才暗中替他扛了一劫，压根没把他和泥坑里的小疯子联系到一起。

### 2. 【五年空白期补丁】五年前改判死刑后，为何硬忍了五年才踹门下凡？
- 并非不想立刻冲下来，而是同时做完了三件必须耗时五年的死局铺垫：
  1. **天庭清场**：连夜把死刑改判为“凡尘抵债”后，在九重天顶住玉清天尊与陆氏派系的反扑追查，血洗并架空司命库档案房，确保没人能二次翻出许知微的死刑卷宗；
  2. **布设南荒眼线**：抽调自己最信得过的三名甲等暗卫换掉南荒巷口街坊，一方面斩断闲杂势力刺杀，另一方面每天暗中传回许知微的一举一动；
  3. **心血炼链与卡准极限**：耗时五年以心血与天律神铁重铸**“四重锁脉同心链”**，直到暗卫急报许知微《太虚定命册》五年续命极限将至、再不落链必神魂溃散，才掐着谷雨雷夜正式踹门落子。

### 3. 三大逆鳞与《天官》式偏爱融合
- **三大逆鳞**：① 受背着他独自赴死；② 外人（如陆沉璧）用轻佻契约或目光染指受；③ 受拿自己的命去换旁人活着。
- **体面护短**：平时哪怕被受使唤劈柴、蹲灶台煮多放三大把红糖的姜汤都甘之如饴；可只要有人敢当众羞辱受“落魄讨饭”，大司命便会在下一瞬把所有体面和杀意一并碾过去，把最高贵的台阶铺到受脚边。

## 二、 受：许知微（字青崖，化名“沈三钱”）

- **核心定位**：**尘埃里不折风骨的落魄贵公子 · 病骨藏锋的驯犬执棋人**
- **《天官》与《燕云》合流风骨**：哪怕窝在漏雨破铺子里拿天界秘典垫咸菜缸、穿半旧狐裘、被街坊记肉账，身上永远带着一份不卑不亢的松弛体面与市井热气——被陆沉璧嘲讽讨饭时懒洋洋反唇相讥，转头还能眯着眼敲诈大司命“呼吸一口南荒灵气算二两银子”。
- **病弱战力与驯犬哲学**：靠天机眼、紫毫借阵与借链剑意周旋八重界域；看穿晏寒江的疯狂占有欲后不逃反撩，主动在寒毒夜嗅他袖口血焦味、在陆沉璧走后勾他白玉带试探底线。

## 三、 中长期对手与核心群像列传

1. **陆沉璧（中州玉京陆氏少主 / 司命副使）**：五百年前万年老二，斯文败类式病态迷恋者；先在南荒当面挑衅触发护食，随后改走**借司命台勘验玉符卡死执法权、借刀杀人**路线，第五卷被许晏反杀送入大牢。
2. **敖凛（东海沉渊蛟主）**：卷四登场，企图强留许知微破译海眼大阵做“专属算师”，逼爆晏寒江三重链纹杀意共鸣。
3. **玉清天尊（司命旧派至高政敌）**：并非脸谱蠢坏，而是经历过上古天裂惨祸后彻底偏执的理念镜像——坚信“牺牲底层散修供养上层神明才是维持三界秩序的唯一解”，与许晏展开终极信念对决。
4. **阿财（吞金辟邪兽幼崽）** / **温不语（百晓楼盲眼掌柜）** / **谢长陵（司命台望风小弟）** / **沈照夜（北境剑阁大师兄）**。

## 四、 第一卷近景配角完整档案卡（支撑第 4–120 章江湖烟火）

### 1. 南荒暗卫三人组（五年前由晏寒江亲调的“甲等戍边营”旧部）
- **王屠户（本名：王猛）**：原司命台铁卫营左队副统领，使三尺阔背斩鬼刀，大拇指内侧磨出月牙剑茧。表面嗓门粗豪、系着油腻围裙天天给许知微送五花肉赊账、半夜爬房顶补瓦片；其实袖袋里永远揣着司命台特制止血散，暗中清理过至少十七波想刺杀许知微的亡命徒。
- **李大娘（本名：李素秋）**：原司命台密探营暗刺，轻功绝顶，挑着两桶井水走青石板连水花都不晃，平时最爱拿半筐带露青菜换许知微替她算“莫须有的鸡毛蒜皮卦”。
- **周三爷（街尾修伞盲老头）**：守在雨巷尽头修竹骨油纸伞的盲老汉，桐油漆罐底下藏着阵眼舆图，手里那把黑漆油纸伞其实能挡元婴一击；后续第 5 章鬼市卖错字铜钱的线索将由他不经意间替两人兜底。

### 2. 第一单元诡案核心人物（第 3–35 章 · 城南赵府画皮阴契案）
- **赵元德（城南赵员外）**：做海货起家的老商贾，表面疼爱女儿、倾家荡产请名师给女儿画皮；**真实面目**：早年船队遇险签了《借寿阴契》濒临破产反噬，竟偷拿独女的生辰八字去鬼市典了命债，所谓的“买命画皮”实则是为了掩盖女儿魂魄正在被一点点抽干的骗局！（照见《赊命契》里“至亲血肉皆可明码标价”的人性悲歌）。
- **赵明珠（赵家小姐）**：天生右脸带一块胎记却性情良善的大家闺秀，以为自己花银子求得容貌不再给父亲丢脸，直到在菱花铜镜里发现影子总比自己慢半拍、且夜半无意识扑向贴身丫鬟的影脚……
- **“盲先生”（无面画师）**：躲在三更鬼市深处的傀儡棋子，案头摆着紫毫与朱砂胭脂盏，专卖带**错字铜钱**的画皮阴契，背后实则连着**万劫潭旧试药残党**在南荒埋下的活人实验桩！
