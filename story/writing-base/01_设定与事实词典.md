## 一、 核心硬数字与时间锚点

- **全书体量**：8 大卷 · 约 **400 章**，每章硬性 **≥ 3,000 纯汉字**。
- **替劫死契总数**：**365 道**（当前进度：`365 / 365`，第 14 章破白露渡喜船案后首消 15 道至 350）。
- **过往时间线**：
  - **500 年前**：万劫潭试药坑底，楚越递出半块硬麦饼（**卷六前绝对保密**）。
  - **480 年前**：同朝为官未相认，楚越代扛太渊九死劫，渗入髓海极寒余毒成十六夜寒毒病根（**卷六前绝对保密**）。
  - **5 年前（三月十五）**：问罪台挨 **36 道削骨鞭**、削仙籍碎灵脉贬凡；楚越带走半本《太虚定命册》封魂续命五年；谢峥连夜篡改死刑判词、清场档案库、调遣退伍暗卫布控南荒并心血重铸四重同心锁命链。
  - **今岁三月十五子夜前（第 1 章）**：《太虚定命册》五年续命期满，白露河停云渡红灯喜船案发，谢峥携《降凡印》登船压灯落链。
  - **今岁三月十五子时（第 2 章）**：楚越贬凡五年**第六十回**雷煞发作，金链收口外偏半分暗抽三成煞气，东厢木桌裂开、渗出焦糊血气。
  - **今岁三月十六清晨至上午（第 2–3 章）**：王猛送大鳜鱼认下“北边远房表弟”；谢峥煮红糖姜汤并切脉预警今晚十六寒毒；陆砚寒乘四抬软轿登门亮《清白赎罪契》被折扇斥退；周三爷递黑竹油纸伞指路青泥渡官窑盐仓。

## 二、 卷一核心地点与器物登记

| 类别 | 名称 | 锁定细节 |
| :--- | :--- | :--- |
| **主据点** | **停云渡 · 赊春堂** | 南荒白露河畔半截架在河木桩上的二层破水阁；西厢楚越住、后屋阿财住、东厢临河空屋谢峥铺草席入住；后檐往西经晒网架至河边茅棚总长 **两丈七尺**（距东厢后窗两丈五）。 |
| **首案核心物** | **七盏红纸灯喜船** | 三月十五子夜漂至停云渡的无人乌篷喜船，船帮为上游十里**青泥渡废官窑盐仓**的老盐卤樟木；三日后为林穗“回门索命夜”。 |
| **楚越随身物** | **“不赊”紫毫笔 / 旧铜钱 / 《太虚定命册》** | 紫毫笔杆刻“不赊”二字，无灵脉借敌方脏墨画反算阵纹；《太虚定命册》曾垫后屋咸菜坛子，第 1 章已原物抛还谢峥擦净收袖。 |
| **谢峥随身物** | **太渊剑 / 四重同心锁命链 / 寒铁镂羽半面** | 白鞘无穗，受先账后刑律非天机官画押不出鞘（但剑鞘可压祟杀人）；初重同心链以谢峥为心方圆**三丈**，收口外偏半分暗设导气缝分流三成雷煞。 |
| **暗线信物** | **缺竖《太平通宝》错字铜钱** | 第 3 章由周三爷首次口头提及（青泥渡灰布长衫牙人付茶钱所用），第 5 章水底暗市正式缴获实物。 |
| **渡口旧部** | **王猛（杀鱼汉）/ 李素秋（挑菜李大娘）/ 周三爷（修伞盲翁）** | 五年前谢峥亲调的甲等戍边营退伍旧部；王猛大拇指内侧有军中阔背直刃月牙老茧，李大娘挑八十斤菜担走滑石板稳如平地，周三爷赠黑竹桐油大伞并暗递盐仓与错字钱线索。 |
